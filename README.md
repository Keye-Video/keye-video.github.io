# Keye Video Team

> **Video Understanding for Foundation Models.**  
> Teaching foundation models to see, reason over, and act on video — from native architectures and agentic harnesses to closed-loop evaluation and grounded RL rewards.

Official homepage: **[https://keye-video.github.io/](https://keye-video.github.io/)**
